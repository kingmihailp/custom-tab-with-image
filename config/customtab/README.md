# CustomTab — папка конфигурации

Поместите сюда изображение заголовка, например `header.png`.

Поддерживаемые форматы: PNG, JPG, GIF (берётся первый кадр).

После добавления файла задайте путь командой:
```
/customtab image set config/customtab/header.png
/customtab image enable
/customtab image resize 60 10
```

Или отредактируйте `customtab-server.toml` вручную.
